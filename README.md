# Food Waste AI System

## Project Overview
This project predicts food waste using Machine Learning and provides intelligent redistribution suggestions using a RAG-based system.

---

## Features
- Food demand prediction using ML (Random Forest)
- RAG system using FAISS + embeddings
- Smart redistribution suggestions for NGOs
- Final AI-generated report output

---

##  Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- FAISS
- Sentence Transformers

---

##  Workflow
Data → ML Model → Prediction → RAG System → Final Report

---

##  Output Example
Predicted Waste: 120 kg  
Suggestions: Donate to NGOs within 4–6 hours
